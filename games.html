ABOUT THE GAME

From Idea To Game

Gun-Duel is one of my game development experiments where I combined HTML, CSS and JavaScript to create an interactive fighting game.

The project focuses on gameplay interaction, player controls, game logic and creating an enjoyable browser-based experience.

This project is also part of my journey of learning development and experimenting with different types of applications.
